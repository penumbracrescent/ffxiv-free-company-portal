# Contributing

Thank you for helping improve the FFXIV Free Company Portal.

## Before opening an issue

- Use the bug-report template for reproducible defects and the feature-request template for proposed changes.
- Search existing issues first.
- Do not post credentials, member records, database dumps, private Discord IDs, access tokens, or security vulnerabilities in a public issue.
- Report security vulnerabilities through the process in `SECURITY.md`.
- Installation-specific privacy and moderation requests belong with that installation's operator, not the open-source maintainers.

## Pull requests

1. Create a focused branch and keep unrelated changes separate.
2. Do not commit `.env`, `SETUP_TOKEN.txt`, backups, PostgreSQL data, uploaded media, Tailscale state, service-account files, dependencies, or build output.
3. Run the relevant service tests. For portal changes, also run the production build.
4. Update documentation and tests when behavior, configuration, privacy handling, or deployment steps change.
5. Complete the pull-request checklist and explain any check that does not apply.

Contributions are accepted under the repository's MIT license. Game assets, names, and third-party data remain subject to the notices in `LEGAL_NOTICE.md` and `THIRD_PARTY_NOTICES.md`.
